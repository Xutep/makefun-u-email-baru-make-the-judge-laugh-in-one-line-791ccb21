## The line

> I finally got my life organized: one folder for 'Important', one for 'Later', and 47 folders all named 'final_final_v2_REAL'.

125 characters — one read, setup ("finally got my life organized") broken
by the punchline (47 folders all named `final_final_v2_REAL`).

## How it works

`main.py` (Python 3 stdlib only, deterministic) writes the line to
`/output/entry.txt` and asserts it is 1–200 characters first.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
